# Cue for macOS

macOS 15+ / Apple Silicon。原生悬浮条：无边框、不激活 Cue 的浮动面板，覆盖全屏应用并跟随所有桌面；点按钮不抢走会议或浏览器的焦点，只有点进输入框才接收键盘。原生宿主采集系统音频和麦克风、执行手动截图并保管设备凭证；回答卡片内的共用页面通过短期凭证直连 OpenAI 转录。

- 控制条：转录（进行中显示计时）、字幕、截图、回答、更多、展开或收起回答卡片。回答卡片一次只显示一轮，可翻看最近一小时的回答；回答深度、资料和连接设置在「更多」里，完整转录与截图在单独窗口。没有聊天切换：回答和转录一样只看最近一小时。
- 字幕只显示面试官（电脑音频）的实时转录，直接取本地转录流的每个片段，不经过服务器、不保存，只在转录进行时显示。
- 输入框内 ⌘ Enter 回答、Esc 收起；全局快捷键 ⌃⌥⌘ Enter 回答、⌃⌥⌘ S 截图、⌃⌥⌘ \ 显示或隐藏。
- 「更多」里的「允许 ChatGPT 遥控」默认开启：ChatGPT 中的 Cue 面板打开时控制条显示手机图标，面板可让电脑开始/停止转录或截图，执行的就是悬浮条按钮；由面板开始的录音在计时旁标「面板」。
- 拖动控制条空白处移动，位置会记住。隐藏后转录继续；菜单栏可重新显示，菜单栏退出会停止采集和连接。
- 只有明确开始转录才申请媒体；启动与重连只恢复连接。
- 登录沿用 `com.siyidu.sage.mac.connection` 钥匙串与既有 SageMac 资料目录。名称改为 Cue 不删除旧登录。
- 设置可打开网页编辑提示词及资料；转录原文和截图预览仍可查看。
- 截图按钮直接通过 ScreenCaptureKit 截取主屏幕当前画面，排除 Cue 自身，保留 PNG 原图。长内容手动滚动后再截，多张图随下一次提问发送。
- 不识别最近应用或网页，不选择后台窗口，不读取窗口文字，不申请辅助功能权限。截图不激活其他窗口、不模拟键盘鼠标；系统录屏授权及指示仍由 macOS 管理，不能承诺不可检测。

## 构建

加载本机 Node / Swift 工具环境后：

```sh
bash apps/macos/scripts/check-offline.sh
bash apps/macos/scripts/build-app.sh
```

产物为 `apps/macos/output/Cue.app`，使用固定的本地签名身份，未公证。构建时先验证原生核心，再构建共用 UI。Node 仅用于构建，不打包进应用。

离线检查覆盖原生连接、转录队列、截止顺序与音频生命周期，并确认产物不导入跨应用辅助功能读取接口。真实屏幕原图上传与 MCP 读回另行验收。

本机首次配置运行 `python3 apps/macos/scripts/local-signing.py setup`。证书和专用构建钥匙串保存在相邻的 `_private/Cue/signing/`，不要提交 Git，也不要在更新时重新生成。此脚本不修改系统证书信任、现有钥匙串条目或媒体权限。后续构建自动复用身份；也可显式设置 `CUE_SIGN_IDENTITY` 使用已有签名证书。没有固定身份时默认停止，只有临时测试显式设置 `CUE_ALLOW_ADHOC=1` 才使用 ad-hoc。

从旧 ad-hoc 版本迁移后可能需要一次系统授权。固定签名的跨版本身份校验通过不等于已验证真实钥匙串和媒体授权持久化。安装前应从菜单栏「Cue → 退出 Cue」正常退出旧进程；新版也支持 ⌘Q。只替换磁盘目录不会更新仍在运行的旧窗口。

`Cue.app/Contents/MacOS/Cue --preview --render-preview /absolute/path.png` 使用合成聊天和经页面桥接注入的合成字幕渲染，不连接生产或开启媒体。真实登录、录音、快捷键与上游时长验收需分别记录。

`--check-connection` 通过相同钥匙串和原生 HTTP 检查已授权连接，仅打印状态与数量。额外显式传入 `--import-existing-materials` 才会把既有五份简历/经历文本写入服务器；它不读取面经目录，不开媒体或模型。真实运行需等待系统钥匙串授权。
