1. 在 ChatGPT 的 Sage 插件页面重新扫描 MCP，确认 Tools 旁出现 `answer.requested`。
2. 在支持 Events 的 Work 云端对话选择 Sage，发送下面的订阅要求。ChatGPT 自动通过 `events/subscribe` 提供回调和签名秘密，服务器验证并保存。
3. Mac Sage 的 **更多 → ChatGPT 订阅** 刷新并选择目标订阅。多个订阅用名称与短编号区分，只向选中的一个投递。

5. 在原 ChatGPT 对话查看答案。Sage 的“ChatGPT 已接收”只表示 webhook 收到；快捷键可在订阅页关闭。

Mac 页面可复制的订阅要求：

> 监听 Sage 的 answer.requested，channel 设为 mac。每次收到事件，使用事件的 request_id 调用 read_interview，读取这次请求固定的转录和截图；按需读取个人资料，然后在本对话用中文回答当前问题。代码题给出 Python 实现、解释和复杂度。连续追问可用上次 request_id 作为 after_request_id 读取新增与修正。

事件只含请求编号、聊天/转录标识、时间和材料数量。`read_interview(request_id=...)` 默认读取按键快照最近一小时；`after_request_id` 比较前次快照并保留修正，`include_older=True` 明确回看快照内更早转录。分页固定请求、基线和范围，同一页可重放，新一场拒绝旧基线。已提交截图不因之后移除附件而改变；新截图留给下次请求。背景资料仍由原工具按需读取。

订阅身份由 OAuth principal、callback URL、事件和规范化 arguments 决定。默认最多授予 24 小时且不超过 OAuth grant 截止时间，ChatGPT 按 `refreshBefore` 续订；事件本身不支持历史重放，cursor 为 null。签名为 Standard Webhooks HMAC-SHA256，challenge 验证后才启用，密钥轮换有 5 分钟双签名窗口。连接时解析并验证 DNS，拒绝非公网地址，连接已验证 IP 同时保留原主机名 TLS 校验；禁止重定向与环境代理。签名秘密和回调地址不进入客户端状态或日志。

一个目标同时最多一个待投递请求。瞬时故障最多六次尝试、指数退避、120 秒内结束，同一 eventId 重试；410/413 不重试。UI 不自动重新 POST 未确认请求，而是查询原编号。停止后续投递不等于停止已在 ChatGPT 开始的回答。重启保留订阅和材料，将未确认请求标为 interrupted，不恢复投递。发布门禁包含待投递请求。

## 使用

Sage 新对话默认 **Responses API**，旧对话保留最后使用的回答方式。再选通用、临场短答或对象设计 / OOD，照常截图、发送、追问。通用已包含代码题要求，重复的算法 / LC 选项已移除；旧聊天的 LC 选择显示为通用，旧客户端请求仍兼容。两种方式使用同一份应用聊天记录，但保留各自的模型会话；首次切到另一种方式会带上此前已发送的聊天和图片。草稿文字、未选择发送的截图不会进入回答请求。API 单独计费，使用服务器现有账户，默认模型 `gpt-6.1-sol`、reasoning `xhigh`，并不等于整个 ChatGPT 产品。

ChatGPT：在 Sage **更多 → 连接 ChatGPT** 复制插件地址与本场开场语。在有开发者模式权限的 ChatGPT 账号中创建自定义 MCP，地址 `https://interview.siyidu.com/mcp`，认证选 OAuth。连接页要求电脑端确认，只授权读取，不能控制 Sage。连接后在 ChatGPT 对话选用 Sage，粘贴本场开场语。原有主提示词可以先发在这个 ChatGPT 对话里。

这个部署复用已有 HTTPS 服务器和 Sage 的认证电脑通道，不需要本机监听端口或额外隧道。普通文本/图片保存在现有私有会话存储中；背景文件仍在电脑 `assistant-workspace/materials`，仅按需读取的片段经服务器提供给模型。支持 UTF-8 md/txt/json/csv；PDF/Word 请先转换为文本。没有批量资料同步、自动截屏或自动接话。

## 四个只读工具

| 工具 | 用途 |
| --- | --- |
| `list_interviews` | 列出历史聊天 ID、标题和更新时间；读取当前转录无需先调用 |
| `read_interview` | 默认 `interview_id="current"` 读取共享转录和截图；明确旧聊天 ID 可读取历史用户文字和可选建议回答；指定旧图 ID 可回看 |
| `list_materials` | 列出电脑上资料路径和版本，可分页 |
| `read_material` | 按路径读取原文，可按版本续页 |

`read_interview` 包含仍在附件栏内、尚未发给 Codex/API 的截图。用户从附件栏移除的图不再进入常规新增读取；历史原件保留，只能以明确图片 ID 回看。输入框的文字草稿永不导出。读取不会消费或删除材料，各 ChatGPT 对话自己保留 `next_cursor`，不得跨 interview_id 混用。`has_more=true` 时继续分页；每页最多两张原图，不通过只保留最后一张来缩小请求。同一 ID 的新 revision 替代旧版，长文本分块带 part/parts，移除记录有 tombstone。相同 cursor 重试重放该页；正常继续读取必须用返回的 next_cursor。每个新游标读取都会检查新增和修正，read_at 明确当前快照截止时间，不声称已实时进入正在回答的上下文。

游标七天有效，最多保留 512 个游标状态与页面重放缓存条目，随私有 SQLite 持久化。过期明确报错，需要重新读取并按 ID/revision 去重；源材料不受影响。授权需要电脑同意、PKCE、限定 ChatGPT 回调、精确 resource 和只读 scope；访问令牌一小时，轮换刷新令牌，整次授权最多三十天，可在 ChatGPT 撤销。

## 维护入口

转录开关独立于聊天，顶部「查看转录」始终查看共用时间线。新建、切换聊天不关闭采集连接、不清空文字。首次回答或 MCP 默认取最近一小时，后续增量包括已提供段落的修正；原文完整保留，MCP 的 `include_older=true` 可明确回看。游标固定首次时间边界，不随每页时间移动。停止转录后可在转录窗口选「新一场转录」，旧场保留，新场拒绝旧游标；聊天本身不清空，模型已经看到的旧内容也不会撤回，需要彻底隔离时另开聊天。旧版客户端会在切换时关闭采集，因此新版协议为 interview-chat-v12，必须同步更新桌面。

- 原生 Codex 主提示词仍在 `assistant-workspace/AGENTS.md`，guides 按需读取。
- API 主提示词在 `apps/server/app/prompts/default.md`；偏好在 `brief.md`、`lc.md`、`ood.md`。每次 API 请求（包括工具结果续接）都重新提供完整主提示词。详细模式 verbosity=high，临场短答=low。
- `OPENAI_RESPONSES_MODEL`、`OPENAI_RESPONSES_REASONING_EFFORT`、`OPENAI_RESPONSES_MAX_OUTPUT_TOKENS` 为独立后端配置。不会把 API key 发往桌面、浏览器或 MCP 输出。
- 插件正式 origin 可用 `INTERVIEW_PUBLIC_URL` 配置，必须与公网 HTTPS 地址一致；支持 loopback 独立测试。
