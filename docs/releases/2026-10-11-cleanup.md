# Cue cleanup — Sites v30, Mac build 30

Removes what the answering tool no longer needs and makes the caption strip scroll back. Behavior otherwise matches Sites v29 / Mac build 29.

## Changes

- Caption strip on Windows, Mac and the web follows the newest words and scrolls back over the interviewer's last ten minutes. Scrolling up stops following until the reader returns to the end.
- Removed the transcript view, screenshot library and image viewer on every platform (Windows card views, Mac transcript window and its menu items). Pending attachments keep their thumbnails and remove button.
- Removed desktop material upload (Windows menu and IPC, Mac menu and panel, `/capture/materials`). Materials are managed only at `/settings`. The Mac `--check-connection` diagnostic no longer imports or lists materials.
- Removed the server image delete endpoint and the server's transcript events to the desktop. `/capture/state` no longer lists transcripts or images.
- Remote control requires protocol version 3 and HTTPS pickup only. Removed WebSocket command polling, the presence broadcast over the socket, transport negotiation (`remote_transport`, `remote_http`, `remote` in `session_ready`) and the version-2 command gate. The desktop always claims commands over `/capture/remote` once connected.
- MCP `read_context` takes only `history`. Removed signed cursors, `since` and `after_seq`. Without `openai/session`, each call returns the latest without saving progress. `SAGE_STORAGE_KEY` is now unused.
- Removed chat-scoped history and `rename_chat`. `history` always returns the last hour.
- Deleted unused files: `scripts/` (Codex host and old server helpers), `.env.example`, `MAC-MIGRATION.md`, `design-qa.md`, `Start Interview.cmd/.vbs`, `assistant-workspace/materials/.gitkeep`, and the cloud's unreferenced `worker/client.generated.js`.

Outer repository: 22 files, +239/−801. Private cloud repository: 15 files, +270/−1113, plus the regenerated `web/app/` bundle.
