# Cue 0.4.0 发布记录

## 已完成的源码

桌面直接 Responses 聊天；Mac 原生浮窗与 Windows 共用 React。单连接双路音频、有序提问标记、独立生成和取消、请求状态、连续聊天、55 分钟上游轮换、连接接管。只读 MCP 使用修订水位分页。网页提供提示词、模型档位、PDF / Word / 文本资料管理。已删通知 Events、准备表运行逻辑、快照运行逻辑、本地资料队列、旧 CLI / VPS 源码和未使用原型。旧数据库与用户资料保留。

基线和历史保存在本地标签、bundle 及私有云端 GitHub 备份。外层公开仓库以子模块固定云端提交，不包含私有云端源码。旧 VPS 工作流只允许手动执行 `legacy-v12`，普通推送不部署。

## 当前验证

- 云端：13 个离线回归通过，包括迟到音频隔离、跨声道提交顺序、接管写入隔离、固定游标、重复请求、连续聊天、取消、设置权限和资料更新。
- 66 分钟测试使用合成时钟与模拟上游，确认轮换及停止后不复活。它不证明真实 Sites / OpenAI 一小时连接稳定性。
- Mac：28 项核心检查及 3 项 App Shot 离线测试通过。共用界面在 WKWebView 预览通过；本地 ad-hoc 签名发布包已构建。
- 桌面采集：25 项通过，1 项仅 Windows 的窗口排除检查在 Mac 跳过。
- Electron 中的共用聊天通过截图附件、流式 Markdown、表格、公式、复制与窄窗口检查；外部网络阻断。
- 网页设置使用真实 Electron DOM、PDF.js 与 Mammoth Worker 验证 TXT / PDF / DOCX 上传和保存；仅 loopback 合成文件。
- 当前可提交源码凭证模式扫描没有发现私钥、OpenAI key 或 GitHub token。
