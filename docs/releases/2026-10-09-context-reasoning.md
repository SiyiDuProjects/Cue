# Cue 0.4.1 build 21：插件最新优先读取与推理摘要

**源码已推送；云端已通过 Sites 发布版本 22，Mac build 21 已安装，Windows 未打包。** 发布与安装验收未调用回答模型；用户亲自开始、说出合成测试句并停止转录。测试句和最新截图已在同一次无参数 `read_context` 调用中返回，但客户端出现本地音频缺口提示，不能据此认定音频无丢失。

## 改动

- 云端 `1b084ca`（私有仓库，已推送）：
  - `read_context` 改为从新到旧分页：无参数调用的第一页包含最新一张截图和最近约 22,000 字转录，`next_cursor` 继续向更早读取。游标升级为 version 2，旧游标返回 409。
  - 转录读取改为按带索引的时间窗口查询，不再扫描永不结束的整条时间线。迁移 `0004` 只追加 `turn_created` 索引和 `messages.reasoning` 字段。
  - Responses 请求推理摘要，以 `answer_reasoning` 流式下发，并随回答保存。账户拒绝摘要参数时（生成前返回 400），去掉该参数重发一次；其他错误不重试。
- 共用回答界面：模型思考时显示摘要；回答开始后折叠为「思路」。Windows 窗口和 Mac 回答页共用这套渲染；Mac 原生 `ChatModel` 同步保存摘要。

## 离线验证

- 云端测试 23/23 通过（新增最新优先分页、时间边界上的修订选择与索引计划、摘要流式保存、拒绝摘要只重发一次）；构建和产物检查通过。
- 本地合成数据：20 万条修订记录下，旧查询返回 5 万条历史、耗时 69 ms（内存数据库，不含网络传输）；新查询返回 70 条、耗时 0.1 ms。这不是 D1 的实测数据。
- 桌面采集测试 31 项通过，1 项 Windows 专用检查跳过；Windows 构建和 Mac 回答页构建通过。界面冒烟测试覆盖摘要先展开、回答开始后折叠，并截图人工查看了两种状态。
- Mac 离线检查 103 项及 8 组上传预算检查通过。build 21 Release 构建签名验证通过，签名身份与 build 20 相同：`identifier "com.siyidu.sage.mac" and certificate leaf = H"d72bccf64b7a2e699fadaf3df2b094f0f6139ca7"`。
