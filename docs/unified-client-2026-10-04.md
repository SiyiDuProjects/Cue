# Sage 客户端统一与原生界面更新

此文是较早的 Responses 聊天版交付记录。当前方向、0.3.1 候选包和 Sites 发布状态见 [统一采集交付记录](unified-capture-delivery-2026-10-04.md)；以下历史验证不代表当前安装状态。

2026-10-04：Mac 0.1.1（build 2）已安装到 `/Applications/Sage.app`；线上网页发布 ID 为 `20261004-unified-sage`。源码仍未提交。旧 Mac 包保留在 `artifacts/releases/20261004-unified-sage/previous-mac/Sage.app`，服务器回滚目录为 `/opt/interview/server.deploy-backups/20261004-unified-sage`。

## 产品行为

- 三端新消息固定使用服务器 Responses；继续旧 Codex 对话也使用 Responses，后端沿用既有跨 provider 上下文接续。旧消息与 v12 后端兼容入口保留。
- Windows 取消 CLI 登录菜单和打包模块；与 Mac 共用只读资料桥接。旧资料目录仍按加密配置恢复，不删除旧 CLI 数据。
- Mac 启动恢复钥匙串中的已有登录。正常界面不再要求服务器地址；首次使用仍沿用现有 Sage 访问凭证体系，没有引入新的账号系统。临时网络失败自动退避重连，过期认证停止重试并提示登录。
- 网页/手机仍通过首次电脑确认及已有安全 Cookie 恢复；所有端保留逐聊天历史、草稿以及独立共享转录。自动恢复连接不启动采集或回答，不重发不确定消息。
- Mac 使用原生 Markdown、表格、公式与代码块，输入区自适应高度、紧凑菜单、系统主题。删去回答上方产品/风格标签，复制移至回答末尾；Mac、网页和 Windows 共用界面均加底部渐隐。
- Mac 的窗口 App Shot 和 Windows 的原有屏幕采集保留平台实现差异；Windows 的可选模拟面试官没有在此轮移植到 Mac。

## 验证

- Mac：31 项核心、54 项运行时、15 项原生排版检查；5 组只读桥接、3 项原生采集桥接及真实 loopback WebSocket 测试通过。浅色、深色、窄窗口截图检查通过，包括表格末行、行内/独立公式、代码、渐隐。
- Web/Electron：构建、33 项 UI 单元检查、64 项采集/模块检查通过，1 项平台专用检查跳过；完整聊天与桌面生命周期合成验收通过，覆盖手机竖屏、IME、停止、历史、旧会话追问、流式上滚/跟随及重启恢复。
- 发布：32 项发布门测试通过。生产通过认证 gate，保留回滚；健康检查确认 v12 和新 release ID，发布门为 active=false/draining=false。公网 HTML 与已验证构建逐字节一致。
- 未调用真实麦克风、音频转录或付费回答模型。Windows 0.1.19 代码和包白名单已更新，此 Mac 没有生成或安装新的 Windows EXE；Windows 真机安装验收仍待完成。
- 安装后的真实自动登录验证正在等待 macOS 钥匙串授权。本地临时签名更新触发系统授权，安全窗口由用户操作；不以离线测试代替真实恢复证明。
