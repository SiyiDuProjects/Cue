# 单题工作区改造验收清单

范围：一题一个工作区；实际代码与未执行建议分开。历史是同题方案快照，不是平行解题分支。已于 2026-09-28 完成本地验收、线上发布和本机 Sage 0.1.2 更新；未调用真实模型或采集真实音频。

1. [x] 主按钮“更新代码”结合当前对话、要求、实际代码和选中截图更新；默认沿用当前思路，跟进对话中已明确的新解法。非代码内容显示“更新分析”。
2. [x] “更多 → 换种解法”独立表达主动换路线的意图，与更新代码共用后台和同一工作区。
3. [x] 补充要求、修改此步、换解法共用输入弹窗；请求失败保留草稿。
4. [x] 第 1 步直接展示第一次修改及相对实际代码的 diff；后续步骤展示累积修改与当步 diff。实际代码按需展开，不单独计为一步。
5. [x] 步骤目录、上/下一步和完整代码只本地浏览；多文件显示当步涉及的文件。
6. [x] 拆分此步：只替换所选步骤，验证最终代码不变，保留前后步骤，后续编号自然顺延。
7. [x] 更新/换解法回到第 1 步；修改此步停在修改处；拆步停在首个子步骤。
8. [x] 仅更新分析或复杂度保留页签、步骤身份和阅读位置，不重挂载面板。
9. [x] 同题历史用“遍历求解”“改用哈希表”等短摘要列出每版；查看旧版不修改实际代码，可回到当前版。
10. [x] 沿用历史解法时基于当前实际代码重建 patch；不回滚外部编辑器。
11. [x] 换题归档旧工作区；“更多 → 回到上一题”恢复上一题记录并提示重新核对编辑器，旧任务不可迟到写入。
12. [x] 当前基线、朴素实现和优化后实现可各有复杂度；复杂度属于所选步骤后的整个实现，未知时留空，支持展开说明。
13. [x] 分析、步骤、复杂度可独立更新；null 保留分析/步骤，空字符串或 [] 明确清空；指定复杂度为 null 清除过期值。
14. [x] 支持朴素到优化、跨区域 patch、改变量名和局部改法；每批变更校验文件版本并原子发布。
15. [x] 工作区与版本保存至私有服务端档案；往场题目使用独立只读入口，重启可查阅，不恢复 Live 或整场对话。
16. [x] 分析使用 Markdown，步骤提示词要求关键意图注释；历史短标题与可展开的补充说明分开。
17. [x] 单元测试、前端构建与合成 Electron 界面闭环，覆盖桌面、横屏和竖屏。
